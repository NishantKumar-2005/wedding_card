# Sanjay ❤ Shikha — Wedding Invitation

React + Vite + motion + lenis. `npm install && npm run dev` · `npm run build` → static `dist/`.

- **All content:** `src/data/wedding.js`. Values that are `TODO…` or contain `____` are hidden automatically
  (family parents, venue name, event times/venues, notes, compliments). Fill them in and they appear.
- **Photos:** drop `1.jpg`, `2.jpg`… (WebP/JPG, ≤150 KB) in `public/photos/`. Missing photos show a lotus placeholder.
- **Music:** add `public/audio/shehnai.mp3` (royalty-free). Without it the music button stays hidden.
- **Before sharing on WhatsApp:** change `og:image` / `twitter:image` in `index.html` to an absolute URL
  (e.g. `https://your-domain.com/og-image.jpg`) and replace `public/og-image.jpg` with your own if desired.
